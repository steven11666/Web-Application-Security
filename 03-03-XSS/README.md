# XSS 實作紀錄

## 1. 實驗環境

* 靶場：OWASP Juice Shop
* 執行方式：Docker 本機環境
* 測試工具：瀏覽器

## 2. 漏洞原理

Cross-Site Scripting（XSS）是指應用程式未妥善處理不可信任的輸入，使其被瀏覽器當成程式碼執行，可能導致使用者操作遭到利用或頁面內容被竄改。

## 3. 實作步驟

1. 啟動本機 OWASP Juice Shop。
2. 找到網站的搜尋欄位。
3. 輸入用於測試 JavaScript 執行的 XSS 測試字串。
4. 觀察瀏覽器是否出現 JavaScript alert 視窗。

## 4. 測試結果

* Alert 是否出現：是

## 5. 防禦方式

* 依輸出情境進行適當的輸出編碼。
* 避免將不可信任的輸入直接當成 HTML 或 JavaScript 執行。

## 6. 學習心得

透過實作，我觀察到不可信任的輸入可能被瀏覽器解讀並執行，理解了 XSS 的基本成因與防禦方向。後續希望將這些觀念應用到 Web 應用程式開發與安全測試中。
